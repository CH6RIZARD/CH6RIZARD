# THE VOID

A live, global social feed on a 3D globe. Spin to any of 199 nations and see what is happening there right now: live TV, city cameras, live streams and reels, next to the threads and posts about that place.

## Features

- **Globe**: 199 nations; each opens a nation page with its live streams, trending topics and community threads.
- **Live wall and reels**: live TV and city cameras streamed straight from the broadcasters' and camera operators' own servers; videos play in YouTube's embedded player.
- **Posts anchored to places, not people**: a post is pinned to the place it is about, never to where the author is. No location permission, no GPS on posts.
- **Anonymous-first**: no sign-up wall. An anonymous account is created the first time you post, and it can be deleted at any time.
- **Messages, search and profile** in a five-tab app.

## Platforms

iOS and Android (native app), plus a web build.

## Tech Stack

- **App**: Expo, React Native, TypeScript
- **Backend**: Supabase (Postgres, auth, edge functions)
- **Web**: Cloudflare Pages
